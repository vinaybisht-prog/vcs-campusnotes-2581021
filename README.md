# CampusNotes

CampusNotes is a lightweight, responsive study-notes manager built with HTML, CSS and vanilla JavaScript.

## Features
- Create, edit and delete notes
- Search across note titles, subjects, tags and content
- Filter by subject and sort notes
- Pin important notes
- Persist notes in the browser using `localStorage`
- Responsive layout for desktop and mobile

## Run locally
Open `index.html` in a modern browser. No build step or package installation is required.

## Data storage
Notes are stored locally in the current browser under the key `campusnotes-v1`. Clearing browser storage removes locally saved notes. This demo does not sync data between devices.

## Project structure
- `index.html` — page structure and note editor
- `styles.css` — responsive styling
- `app.js` — note CRUD, search, filtering and local storage

How to Use CampusNotes
Open index.html in your browser.
Click New Note to create a note.
Enter the title, subject and content.
Use the search bar to find specific notes.
Filter notes by subject.
Pin important notes for quick access.
Edit or delete notes whenever required.

Manual Testing Checklist
Create a new note.
Search for a note by title.
Filter notes by subject.
Pin and unpin a note.
Edit an existing note.
Delete a note.
Refresh the browser and verify saved notes.

Browser Compatibility
Use a modern browser with JavaScript and Local Storage enabled.
